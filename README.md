# Image Embedding Visualizer

An interactive image gridding and embedding visualization project for reviewing image classification results.

## What Is Included

- `app/` contains the final D3 visualization interface.
- `data/classification_results.json` contains MobileNetV2 top-1 predictions.
- `data/tsne_results.json` contains 2D t-SNE coordinates.
- `data/images/` contains the 600 images used by the current visualization.
- `data/words.txt` is used to decode the source WordNet IDs in image filenames.
- `app/vendor/d3.v7.js` contains the local D3 dependency.
- `scripts/pca_reduce.py` is the data-generation script used to create the classification and embedding outputs.
- `server.js` serves the project locally so JSON and images can be loaded by the browser.

## Run

From this folder:

```powershell
node server.js
```

Then open:

```text
http://localhost:4173/app/
```

If port `4173` is already busy, the script will automatically try the next available port and print the URL.

## Current Workflow

1. `scripts/pca_reduce.py` extracts ResNet101 features, predicts classes with MobileNetV2, reduces features with PCA, then computes t-SNE.
2. The script writes `features.json`, `classification_results.json`, `pca_results.json`, and `tsne_results.json`.
3. `app/app.js` loads the generated JSON files and renders the interactive dashboard.

## Main Views

- `Image Grid` is the default view for image gridding. It supports grouping by dataset label, model prediction, prediction check, or no grouping.
- `Embedding Map` keeps the original t-SNE view. Use `Pan` to move around after zooming, and `Select` when you want to box-select points.
- Grid controls let you filter matches/mismatches, sort by confidence/date/name, and resize image tiles.

## Notes

- The current dates in `classification_results.json` are simulated random dates generated by `pca_reduce.py`.
- The visualization can color by MobileNetV2 prediction, Tiny ImageNet source label, or whether those labels match.
- MobileNetV2 predictions are ImageNet pretrained top-1 labels; use the dataset-label mode when you need the ground-truth category view.
- The old experimental folders are kept locally but are intentionally excluded from the GitHub-ready project.

## Classification Accuracy Plan

The current `classification_results.json` was produced with a pretrained ImageNet MobileNetV2 model. That is useful as a baseline, but it is not the same as a classifier trained or fine-tuned for the selected Tiny ImageNet subset.

For presentation now, use the new `Color and distribution` control:

- `Model prediction` shows what MobileNetV2 predicted.
- `Dataset label` shows the source class decoded from the Tiny ImageNet WordNet ID in each filename.
- `Prediction check` highlights whether the prediction text matches one of the source-label terms.

For a stronger future classifier, regenerate the JSON with top-5 predictions and then fine-tune a model on the 200 Tiny ImageNet classes or on the smaller class subset used in `data/images/`.
